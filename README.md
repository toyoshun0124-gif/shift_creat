# シフト作成アプリ

アルバイト・パートスタッフの「希望シフト提出」「シフト自動作成」「再調整」をまとめて行える、シフト管理Webアプリです。
これまでマネージャーが手作業で行っていたシフト表作成を、希望日程の収集から作成・再調整まで自動化し、作業時間を削減することを目的としています。

## 主な機能

### マネージャー向け
- **シフト作成依頼**：従業員から提出された希望シフトをもとに、シフト案を5パターン自動生成
- **再調整通知**：従業員からの再調整依頼（従業員ID・日程・時間帯）の一覧確認
- **シフト再調整**：再調整依頼を反映してシフト案を作り直し
- 作成したシフト案から1つを選択し、確定・全体へ共有

### 従業員向け
- **希望シフト提出**：対象月の希望シフトをまとめて入力・提出
- **シフト閲覧**：確定・共有されたシフトの確認
- **再調整申請**：確定後のシフトに対する変更希望をマネージャーへ申請
- ログイン後、表示名（お名前）を自分で設定

### 共通
- マネージャー／従業員それぞれ専用のログイン画面
- 入力ミス・文字数超過・提出締切超過・ログイン誤りなどのエラーハンドリング
- 入力途中の内容の自動保存・復元（下書き保存）

## 技術構成

| 項目 | 内容 |
|---|---|
| フロントエンド | Vite + React |
| API | Vercel Functions（`api/` ディレクトリ） |
| データベース | PostgreSQL（Vercel経由のNeon） |
| ORM | Prisma |
| デプロイ先 | Vercel |

ブラウザから直接データベースへは接続せず、必ず `api/` 配下のサーバー関数を経由します。

## ディレクトリ構成

\`\`\`
api/                  サーバーサイド関数（認証・希望提出・シフト生成 等）
prisma/               DBスキーマ・マイグレーション・シードスクリプト
src/
  pages/              画面ごとのコンポーネント
  components/          共通UIコンポーネント
  lib/                 API通信・認証状態管理
scripts/              ローカル開発用の補助スクリプト
docs/                  仕様書
\`\`\`

## セットアップ


- 不正な時間帯の入力（例：25:00 など） → 「入力ミスがあります」と表示
- 提出締切を過ぎた送信 → 「締め切られている」と表示
- 入力途中での画面終了 → 自動保存・下書き保存により復元可能
- ログインの誤り（役割違い・ID/パスワード誤り） → それぞれ専用のエラーメッセージを表示
