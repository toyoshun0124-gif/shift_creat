1.改善ポイント名
①従業員がでシフトを1か月入力できるようにする
2.理由
今はシフトを入力する日は1日のみなので、いちいち日付を入力するのは面倒。シフトを1ヶ月ごとに分けて入力できるようにします。
3.画面フローへの影響
④結果の表示に影響します。
従業員が希望シフト提出ボタンを押したら、1ヶ月の日にちが画面
に出る。そのため1ヶ月分のシフトを1度に提出できるようにします。
4.新しいイレギュラーケース
①1ヶ月の内、１つでもシフト入力ミスがあった場合、「入力ミスがあります」と表示。先に進ませない。
②途中で画面を閉じた場合、入力したのが消えないように、保存ボタンを追加する。ボタンを押せば閉じる前の画面に復帰できる。
